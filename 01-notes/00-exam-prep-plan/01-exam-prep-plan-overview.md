# Exam Prep Plan Overview — AWS Certified Solutions Architect Associate (SAA-C03)

**Status:** ✅ Complete | **Course length:** 15 min | **Level:** Fundamental
**Source:** AWS Skill Builder → Exam Prep Plan (learning plan, 18 trainings, ~18h 25m total)

## What this course is
A short orientation to the Exam Prep Plan: it explains the four steps and gives guidance on how much time to spend on each.

## The 4-step plan

| Step | Goal | What you do |
|------|------|-------------|
| 1 | Get to know the exam | Read the exam guide, take the Official Practice Question Set to see the exam style |
| 2 | Refresh AWS knowledge and skills | Fill gaps with digital courses; practice with Builder Labs, Cloud Quest, or Jam |
| 3 | Review and practice | Go domain by domain (review videos, practice questions, flashcards, SimuLearn labs); learn test-taking strategy |
| 4 | Assess readiness | Take the Official Practice Exam |

## Key takeaways
- The plan mixes four kinds of learning: **videos**, **exam-style questions/flashcards**, **hands-on labs**, and **a full-length practice exam**.
- **AWS SimuLearn** = a generative-AI-powered scenario where you design a solution for a fictional customer, then build it in a live console lab.
- The Official Practice Exam uses the same question count, time limit, and scaled scoring as the real exam, so it is the best readiness check.
- Some content may need an AWS Skill Builder subscription.
